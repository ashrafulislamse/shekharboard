├── iOS: 20, 29, 40, 58, 60, 76, 80, 87, 120, 152, 167, 180, 1024 (px)

├── @3x: 72×72 (px) - xxhdpi

CATEGORY TILES:
├── Small: 100×100 (px)

## 🔄 Prompt Modifiers Reference

### Style Modifiers
```
QUALITY:
--q 2          (higher quality, slower)
--s 250        (stylization level)
--style raw    (more literal interpretation)

ASPECT RATIOS:
--ar 1:1       (square - icons, tiles)
--ar 16:9      (landscape - banners)
--ar 9:16      (portrait - splash screens)
--ar 3:2       (icon sheets)

VERSION:
--v 6          (Midjourney v6 - recommended)
--v 5.2        (alternative)
```

### Negative Prompts (Add to all)
```
EXCLUDE FROM ALL PROMPTS:
"--no scary, dark, realistic, complex, detailed texture, 
photorealistic, 3D render, shadow heavy, adult themes, 
violence, text errors, blurry, low quality, watermark"
```
