## 🎯 Category Style Guidelines

### Letter & Number Standards

```
BASE STYLE (Apply to ALL alphabet/number prompts):
├── Art Style: "cute kawaii style", "children's book illustration"
├── Character: "letter/number with friendly face", "big eyes on character"
├── Rendering: "flat design", "soft shadows", "bold clean outlines"
├── Colors: "vibrant primary colors", "each letter unique color"
├── Background: "transparent background", "white background for extraction"
├── Quality: "high quality", "vector art", "4K", "crisp edges"
└── Mood: "educational", "friendly", "fun to learn"

CONSISTENCY RULES:
├── Bengali script clearly readable and accurate
├── Face positioned naturally on letter curve
├── Same eye style (big, round, sparkly)
├── Bold letter weight for visibility
├── Associated object shown beside letter
├── Transparent/white background for app integration
├── Each vowel/consonant group has color theme
└── Numbers paired with counting objects

NEGATIVE PROMPTS (Add to all):
"--no realistic, photorealistic, thin lines, 
complex design, dark colors, incorrect script, 
3D render, adult style, hard to read"
```
