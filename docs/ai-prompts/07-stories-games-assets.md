## 🎯 Category Style Guidelines

### Story & Game Asset Standards

```
BASE STYLE (Apply to ALL story/game prompts):
├── Art Style: "cute kawaii style", "children's book illustration"
├── Character: "expressive characters", "consistent mascot style"
├── Rendering: "flat design", "soft shadows", "clean outlines"
├── Colors: "warm pastel palette", "child-friendly colors"
├── Background: "transparent or contextual", "white for extraction"
├── Quality: "high quality", "vector art", "4K", "clean edges"
└── Mood: "engaging", "playful", "educational", "encouraging"

STORY ILLUSTRATION RULES:
├── Consistent character design across scenes
├── Clear visual storytelling
├── Simple backgrounds that don't distract
├── Expressive character emotions
├── Bengali cultural elements where appropriate
└── Age-appropriate content (1-5 years)

GAME ASSET RULES:
├── Clear, recognizable shapes
├── High contrast for visibility
├── Consistent style across game elements
├── Celebratory feedback assets
└── Encouraging error state assets

NEGATIVE PROMPTS (Add to all):
"--no realistic, photorealistic, scary, dark, 
violent, complex details, 3D render, 
adult themes, text errors"
```
