## 🎯 Category Style Guidelines

### Animal Illustration Standards

```
BASE STYLE (Apply to ALL animal prompts):
├── Art Style: "cute kawaii style", "children's book illustration"
├── Character: "friendly face", "big round eyes", "soft rounded shapes"
├── Rendering: "flat design", "soft shadows", "clean outlines"
├── Colors: "soft pastel colors", "warm tones", "gentle saturation"
├── Background: "soft leaf green (#7FBA96)", "simple", "minimal"
├── Quality: "high quality", "vector art", "4K", "clean edges"
└── Mood: "friendly", "approachable", "educational", "non-scary"

CONSISTENCY RULES:
├── Same eye style across all animals (big, round, sparkly)
├── Similar level of detail/simplification
├── Consistent shadow direction (bottom-right)
├── Same background color for category unity
├── Proportions suitable for young children (head slightly larger)
└── No teeth showing (can be scary for toddlers)

NEGATIVE PROMPTS (Add to all):
"--no scary, aggressive, realistic, detailed fur texture, 
sharp teeth, claws visible, dark shadows, complex background, 
photorealistic, 3D render, adult style, violence"
```

## 📐 Export Specifications

### Tile Sizes for App
```
LEARNING TILE (Main display):
├── @1x: 150×150 px (mdpi)
├── @2x: 300×300 px (xhdpi)
├── @3x: 450×450 px (xxhdpi)
└── @4x: 600×600 px (xxxhdpi)

DETAIL VIEW (Full screen):
├── @1x: 256×256 px
├── @2x: 512×512 px
└── @3x: 768×768 px

THUMBNAIL (Lists/Favorites):
├── @1x: 64×64 px
├── @2x: 128×128 px
└── @3x: 192×192 px
```

### File Naming Convention
```
PATTERN: animal_[bangla-transliteration]_[variant]_[size].png

EXAMPLES:
├── animal_goru_default_512.png      (Cow)
├── animal_biral_default_512.png     (Cat)
├── animal_kukur_happy_512.png       (Dog - happy variant)
├── animal_bagh_default_512.png      (Tiger)
```
