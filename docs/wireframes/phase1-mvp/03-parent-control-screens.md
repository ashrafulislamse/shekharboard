### 🔐 Security Logic

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   LOCKED STATE (After 3 wrong attempts):               │
│                                                         │
│    ╔═══════════════════════════════════════════════╗    │
│    ║                                               ║    │
│    ║              🔒                               ║    │
│    ║              64dp icon                        ║    │
│    ║              Color: #C75146                   ║    │
│    ║                                               ║    │
│    ║              ২৫ সেকেন্ড অপেক্ষা করুন         ║    │
│    ║                                               ║    │
│    ║                                               ║    │
│    ║              ┌─────────────────┐              ║    │
│    ║              │                 │              ║    │
│    ║              │   00:25         │              ║    │
│    ║              │                 │              ║    │
│    ║              └─────────────────┘              ║    │
│    ║              Countdown timer                  ║    │
│    ║              Headline/32sp                    ║    │
│    ║              Animated (pulse)                 ║    │
│    ║                                               ║    │
│    ╚═══════════════════════════════════════════════╝    │
│                                                         │
└─────────────────────────────────────────────────────────┘

Logic Flow:
├── Generate: num1 (1-5) + num2 (1-5)
├── Max answer: 10 (single digit or "10")
├── Wrong attempt 1: Shake animation + haptic
├── Wrong attempt 2: Shake + show hint
├── Wrong attempt 3: Lock for 30 seconds
├── After lockout: Reset to 0 attempts, new question
└── Correct: Dismiss dialog, navigate to settings
```

### 🎬 Animations

| Element | Animation | Trigger |
|---------|-----------|---------|
| Dialog | Scale up (0.9→1) + fade | On open |
| Wrong Answer | Shake X-axis ±10dp, 4 cycles | On submit wrong |
| Number Press | Scale 0.95 + darken | On tap down |
| Lock Icon | Pulse scale (1→1.1→1) | While locked |
| Countdown | Tick animation | Every second |

## 🔒 Security & Privacy Principles

1. **Math Gate Security:**
   - Questions use Bangla numerals (১, ২, ৩...)
   - Max sum = 10 (simple for parents)
   - 30-second lockout after 3 wrong attempts
   - New question generated each time

2. **Data Privacy:**
   - All analytics stored locally only
   - No cloud sync or upload
   - Parent can clear all data anytime
   - No personal identifiers collected

3. **Child Safety:**
   - Session timer prevents overuse
   - No external links accessible to child
   - No in-app purchases accessible to child
   - All purchases require math gate
