```
CORRECT TAP:
├── Card border: #7FBA96 (green)
├── Card background: Pulse #7FBA9630
├── Icon: Bounce animation
├── Sound: Happy "ding!" chime
├── Points: "+10" float up animation
├── Voice: "সঠিক!" (Correct!)
└── Auto-advance: 800ms delay

WRONG TAP:
├── Card border: #C75146 (red) briefly
├── Card: Shake X-axis
├── Sound: Soft "try again" tone
├── No points deducted (child-friendly)
├── Voice: "আবার চেষ্টা কর" (Try again)
└── Card returns to normal state

ROUND COMPLETE:
├── All dots filled animation
├── Score summary popup
└── "Next" or "Finish" button
```

### 🎬 Card Flip Animation

```

├── Duration: 300ms
├── Type: 3D Y-axis rotation
│
├── First half (0-150ms):
│   ├── Card rotates Y: 0° → 90°
│   └── Scale: 1 → 0.95
│
├── Midpoint (150ms):
│   └── Swap content (back → front)
│
├── Second half (150-300ms):
│   ├── Card rotates Y: 90° → 0°
│   └── Scale: 0.95 → 1
│
└── Curve: easeInOutCubic

MATCH ANIMATION:
├── Both cards pulse scale (1 → 1.1 → 1)
├── Background fade to green
├── Sparkle particles
├── Success sound
└── Duration: 500ms

NO MATCH ANIMATION:
├── Both cards shake
├── Brief red tint
├── Flip back to face down
├── Delay: 1000ms viewing time
└── "Try again" voice
```

## 🎮 Game Design Principles

```
CHILD-FRIENDLY DESIGN:
├── No time pressure (optional timer)
├── No penalties for wrong answers
├── Immediate positive feedback
├── Clear, large touch targets (min 80dp)
├── Simple, recognizable icons
├── Voice guidance throughout
└── Progress always visible

EDUCATIONAL VALUE:
├── Vocabulary reinforcement
├── Visual recognition
├── Memory development
├── Counting skills
├── Color recognition
├── Sound association
└── Fine motor skills (drag/drop)

ACCESSIBILITY:
├── High contrast options
├── Voice for all text
├── Large touch targets
├── Simple navigation
└── Consistent patterns
```
